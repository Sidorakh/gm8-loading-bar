# GM8 Loading Bar

Does your project need some retro flair? Why not try the GM8 Loading Bar today! Simply import this prefab into your game, and you'll have a loading bar that would make Mark Overmars himself weep from its sheer beauty!

## Installation and usage

You can install this as a Prefab via the GameMaker Kitchen registry, you can follow this guide to add this package registry to your IDE: https://github.com/tabularelf/Libraries-and-the-state-of-prefabs/blob/release/adding-gmk-registry.md

Once you've added the registry, install `@sidorakh/gm8-loading-bar` from the list of packages to put it in your local prefab library, and then right click the entry in your prefab library and select "Add Collection Reference" to add it to your game
